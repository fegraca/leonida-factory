Política de Privacidade

Atualizada em 19/11/2026

O que o app acessa

Com a autorização do dono do canal, o leonida-factory usa os escopos youtube.upload (enviar vídeos) e youtube.readonly (ler o nome do canal para confirmar a conta autorizada).

Como os dados são usados

O token de acesso fica guardado apenas no computador e no servidor privado do dono do canal e serve só para publicar os vídeos do próprio canal. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Dados de outras pessoas

O app não coleta dados de espectadores nem de outros usuários do YouTube.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao revogar, o token deixa de funcionar e é apagado.

O uso dos dados do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. O app também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.
